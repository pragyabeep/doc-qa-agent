# CloudSync Getting Started

## Plans and pricing

CloudSync has three plans.

- Free: 5 GB storage, 1 user, maximum file size 2 GB.
- Pro: 2 TB storage, up to 10 users, maximum file size 50 GB. Price is $12 per user per month when billed monthly, or $10 per user per month when billed annually.
- Business: 10 TB pooled storage, minimum 3 users, maximum file size 50 GB. Price is $20 per user per month when billed monthly, or $17 per user per month when billed annually.

## Installing the desktop app

The desktop app supports macOS 12 or newer, Windows 10 or newer, and Ubuntu 22.04 or newer. Download the installer from the Downloads page in your account and sign in with your CloudSync email and password.

## Pausing and resuming sync

Click the CloudSync tray icon and choose Pause Sync. Choose Resume Sync to start again. Changes made while paused are uploaded when sync resumes.

## Selective sync

Open Preferences, then Sync, then Choose Folders to keep some folders in the cloud only. Cloud-only folders do not use local disk space.
