# Error Code Reference

## E-3010: Authentication failed

The saved sign-in token is invalid or expired. Sign out of the desktop app, sign in again, and repeat on every device if you recently changed your password.

## E-4021: Sync conflict

The same file was changed on two devices before either change finished syncing. CloudSync keeps both versions. The second version is renamed with the suffix "(conflicted copy, device name)". To fix it, open the Conflict Resolver from the tray icon, compare the two versions, and choose Keep Both, Keep Local, or Keep Cloud.

## E-4032: Storage quota exceeded

Your account has used all of its storage. Free up space by emptying the trash, or upgrade to a plan with more storage. Uploads resume automatically once space is available.

## E-4107: File path too long

On Windows, a file path longer than 260 characters cannot be synced. Shorten the folder or file names, or move the folder closer to the drive root.

## E-5001: Server unavailable

CloudSync servers could not be reached. Check the status page. The app retries automatically with increasing delays, so no action is needed unless the error lasts more than 30 minutes.
